# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Hanbova seriously. If you discover a vulnerability, please report it responsibly:

* **Email**: security@hanbova.me
* **PGP Key**: Available on request / keybase.

Please include:
* Description of the vulnerability
* Steps to reproduce the issue
* Potential impact

We will respond within 48 hours and work with you to remediate before public disclosure.
